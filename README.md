# Generative AI - Lab Assignment 03: Text Generation using GPT-2

## Aim
To generate coherent text using a pre-trained Transformer autoregressive model (GPT-2) and evaluate decoding strategies including greedy search, sampling, and temperature control for generating short study tips.

## Software and Libraries Used
- Python
- Google Colab / Jupyter Notebook
- PyTorch
- Hugging Face Transformers (`openai-community/gpt2`)
- Matplotlib

## Repository Contents
- `LAB_3.ipynb`: Python Jupyter Notebook implementing GPT-2 tokenizer, model pipeline, prompt conditioning, and experiments with various decoding strategies (greedy, temperature scaling, top-k/top-p sampling).
- `Lab 3.docx`: Comprehensive lab report document detailing transformer mechanics, self-attention, generation parameter comparison, and output samples.
